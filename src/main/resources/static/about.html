How it Works

This app does not upload your video files to a server. Instead, it streams the file directly from your device.

  1. Create a Room Code.
  2. Share the Room Code with your friends.
  3. Both of you select the same video file from your own computers.
  4. The server checks if the files match.
  5. If they match, play/pause is synced automatically!

Features

  • Privacy First: Your videos never leave your device.
  • Perfect Sync: Play, Pause, and Seek are instant.
  • Chat & Reactions: Send messages and floating hearts.
  • Auto-Resume: Handles network drops and phone locks.
